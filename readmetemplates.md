# What is this branch for?

This branch is to create a set of html "templates".

## Why are you using templates?

Rather than having multiple hundred different html files for specific pages of my website, I'm instead going to have about a dozen "templates".
These templates will be filled with specific information but displayed in the same way.
E.G.
Each user profile will adhere to the basic layout of a "user profile template", but the data displayed will change depending on who's profile is being visited.
etc with all the other templates.

## How are you going to use this in the future?

Well you see this is very useful for a thing called a framework, as I can hand it an html template and say "put this data here" and it will go "okay" and go and get the data and put it there. _jazz hands_
